# 剪贴板历史 需求文档

版本：v3（2026-11-08）    状态：已确认（v3 常用语去掉标题）    强度：L2

## 一、要解决的问题

Windows 剪贴板只记得**最后复制的那一次**。复制了一段代码，转头又复制了个链接，前一段就没了，
只能回去重新找、重新选、重新复制。手机输入法自带剪贴板历史，翻一下就能找回前几条，Windows 没有。

真正难受的场景：

- 在网页上看到一段要用的文字，复制了，切到编辑器又复制了别的东西 → 前面那段找不回来了
- 一天里复制了几十次，晚上想找早上复制的一个链接 → 完全没记录
- 想连粘三条不同的内容 → 只能来回切换窗口反复复制

## 二、方案概述

一个在后台安静运行的小工具。你复制过的**文字**它都记着，保留 **7 天**，过期的自己删掉。
需要找回时点一下托盘图标，弹出列表，选中哪条就自动放回剪贴板，接着 Ctrl+V 粘出来就行。

和手机输入法剪贴板的用法一致：**不用提前准备，复制完就不用管，要用的时候翻出来。**

另外提供一块**常用语**：你可以手动存几条经常要粘的内容（地址、邮箱、固定话术），
它**不受 7 天限制、永不自动删除**，随时点一下就复制走。

## 三、用户故事

1. 作为用户，我复制了三段不同的内容，想把第一段再粘一次，不用回去重新复制
2. 作为用户，我想找到**昨天晚上**复制过的一个链接
3. 作为用户，我反复复制同一段文字，列表里**只出现一条**（按最新时间置顶），不会堆成十条
4. 作为用户，7 天前复制的东西自动消失，我不需要手动清理
5. 作为用户，我开机后什么都不用做，它自己就在跑
6. 作为用户，我重启电脑后，之前的历史**还在**
7. 作为用户，7 天可能积累几百条，我能**打字搜索**快速定位
8. 作为用户，我点列表里的一条，剪贴板立刻变成它，我 Ctrl+V 就能粘出来
9. 作为用户，我复制了密码这类敏感内容，能**手动删掉那一条**
10. 作为用户，我想一次性清空所有记录
11. 作为用户，我暂时不想让它记录（比如在录屏），可以**暂停记录**
12. 作为用户，我关掉窗口后程序**还在托盘里**，不会真的退出
13. 作为用户，我把「xxx@xx.com」存成常用语，以后一点就复制，不用每次找
14. 作为用户，我**只填内容就行**，不用另起标题（v3 改：标题栏是多余的一道必填）
15. 作为用户，我能**编辑和删除**某条常用语
16. 作为用户，常用语**永远不会因为过期而消失**

## 四、实现决策（已拍板）

| 项 | 决定 | 理由 |
|---|---|---|
| 语言 | Python 3.14.6（`D:\pyhj\python.exe`） | 本机已有，且带 tkinter |
| 界面 | tkinter + `ttkbootstrap`（深色主题 darkly） | tkinter 默认外观是 90 年代风格；ttkbootstrap 只加一个包就能拿到现代扁平样式，比自己手绘几百行省事 |
| 存储 | SQLite 单文件 `data.db` | 标准库自带；几万条也不卡 |
| 托盘 | `pystray` + `Pillow` | Pillow 本机已有，只需装 pystray（49KB） |
| 记录内容 | **只记纯文本** | 图片会让 7 天数据涨到几个 GB |
| 记录方式 | 每 0.4 秒检查一次剪贴板是否变化 | 比挂钩子简单，漏记风险极低 |
| 去重 | 对内容算 SHA256，重复的只更新时间并置顶 | 反复复制同一段不会堆记录 |
| 过期 | 保留 7×24 小时；启动时 + 每小时清理一次 | |
| 单条上限 | 超过 10 万字符不记录 | 防止巨型文本撑爆库 |
| 粘贴方式 | 只把内容写回剪贴板，由你按 Ctrl+V | 不模拟键盘，避免误粘到别的窗口 |
| 自启 | 启动文件夹放一个快捷方式 | 可在任务管理器里随时关掉 |
| 界面入口 | **只有托盘图标**，不做全局快捷键 | 避免和别的软件抢 Ctrl+Shift+V |
| 常用语 | 单独一张表，独立于历史；**不参与 7 天清理** | 常用语是长期资产，不该被过期机制误删 |
| 常用语表单 | **只有内容**一个输入框 | 常用语本就是一句话点一下就用，多一个标题只是多一道必填 |

## 五、验收标准

- [ ] 复制一段文字 → 打开列表能在最上面看到它
- [ ] 再复制另一段 → 两段都在，新的在上面
- [ ] 反复复制同一段 5 次 → 列表里仍然只有 1 条，且跳到最上面
- [ ] 点列表里任意一条 → 提示「已复制」，随便找个输入框 Ctrl+V 能粘出那条内容
- [ ] 在搜索框打几个字 → 列表只剩包含这几个字的
- [ ] 右键某条 → 能删除那一条
- [ ] 托盘右键菜单里有：打开 / 暂停记录 / 清空全部 / 退出
- [ ] 点窗口的 × → 窗口消失但程序还在托盘（托盘图标仍在）
- [ ] 把某条记录的时间改到 8 天前 → 下次清理后它消失
- [ ] 重启电脑 → 历史记录还在，程序自动在托盘
- [ ] 复制一张图片 → 不记录（不会报错，也不会存垃圾）
- [ ] 点「＋ 添加常用语」→ 只填内容 → **保存按钮不用拉伸窗口就能看见** → 保存后出现在页签
- [ ] 点某条常用语 → 提示「已复制」，能粘贴出它的内容
- [ ] 把某条常用语的时间改到 30 天前 → 它**仍然在**（不参与过期）
- [ ] 右键常用语 → 能编辑、能删除

## 六、不做什么（Out of Scope）

- **不记图片、不记文件本身**（复制文件时只记下路径文字）
- **不自动粘贴**：不会替你按 Ctrl+V 粘到当前窗口，只放回剪贴板
- **不做全局快捷键**（你选了只要托盘）
- **不做云同步 / 多设备**
- **不加密**：本地 SQLite 明文存储，懂电脑的人打开文件能读
- **不做分类、标签、收藏**
- **常用语不做分组、不做拖拽排序、不做导入导出**
- **不做 Windows 原生以外平台**
